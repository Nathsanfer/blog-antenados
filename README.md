# 📚 Antenados - Blog Escolar

Um blog escolar moderno e responsivo desenvolvido com Vue 3 e Vite para compartilhar conhecimento, artigos educativos e notícias da comunidade escolar.

---

## 📖 Sobre

**Antenados** é uma plataforma digital para a comunidade escolar que oferece:

- ✍️ **Artigos Educativos** - Conteúdo informativo de qualidade
- 📰 **Jornais Escolares** - Publicações periódicas da escola
- 🎨 **Interface Intuitiva** - Design responsivo e amigável
- 📱 **Totalmente Responsivo** - Funciona em desktop, tablet e mobile

---

## 🤝 Projeto de Extensão - Conectados pela Comunidade

### Iniciativa Acadêmica

Este projeto faz parte do **Programa de Extensão Universitária "Conectados pela Comunidade"**, uma iniciativa inovadora que visa fortalecer os laços sociais e promover o desenvolvimento contínuo de comunidades locais.

### 🎯 Nossa Visão

O programa **"Conectados pela Comunidade"** é fundamentado em princípios de:

- **Inclusão Social** - Envolvimento ativo de todos os membros da comunidade
- **Participação Colaborativa** - Criação de redes de conexão sólidas
- **Inovação Social** - Desenvolvimento de soluções criativas para desafios reais
- **Desenvolvimento Sustentável** - Fortalecimento de famílias vulneráveis

### 📌 Objetivo

Através de uma abordagem aberta e colaborativa, buscamos criar um ambiente propício para fortalecer os laços sociais e capacitar indivíduos a serem **agentes de mudança em suas próprias comunidades**, promovendo:

- 🌍 Conexão entre a comunidade acadêmica e organizações sociais
- 🎓 Compartilhamento de conhecimento e experiências
- 💡 Inovação em soluções para desafios comunitários
- 👥 Preparação de líderes comunitários

### 🎓 Sobre o Blog Antenados

O **Antenados** funciona como ferramenta central para este programa, permitindo que a escola e a comunidade local:

- Compartilhem histórias de sucesso e aprendizados
- Disseminem informações importantes sobre iniciativas comunitárias
- Fortaleçam a comunicação entre alunos, professores e famílias
- Documentem o impacto social do programa de extensão

## 🚀 Recursos

### Funcionalidades Principais
- 📑 Página inicial com posts e jornais recentes
- 🔍 Busca de artigos por título, categoria e autor
- 📂 Filtro por categorias
- 🎠 Carrossel dinâmico de imagens
- 📖 Detalhes completos de cada artigo
- 🔗 Navegação fluida entre seções
- 💾 Dados gerenciados via Supabase

### Páginas
- **Home** - Visão geral com posts e jornais recentes
- **Blog** - Lista completa de artigos com filtros
- **Detalhes do Artigo** - Conteúdo completo com carrossel de imagens
- **Perfil** - Informações do usuário (em desenvolvimento)
- **Criação** - Editor de conteúdo (em desenvolvimento)

---

## 🛠️ Tecnologias

- **Frontend:** Vue 3 + Vite
- **Roteamento:** Vue Router
- **Backend:** Supabase (PostgreSQL)
- **Estilização:** CSS Vanilla (Scoped)
- **Gerenciamento:** Composables Vue
